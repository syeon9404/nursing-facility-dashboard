# 요양(병)원 시설 현황 지도

전국 요양(병)원의 시설 특성과 소방대응여건을 공간적으로 조회, 분석하기 위해 구축한 웹 기반 지도 서비스

🔗 서비스  
https://syeon9404.github.io/nursing-facility-dashboard/

## 구축목적

전국 요양(병)원 시설의 입지, 건축형태, 규모, 입소자 특성 및 주변 소방대응여건 등의 정보를 하나의 공간정보 DB로 통합

- 전국 요양(병)원 공간적 분포 파악
- 시설별 입지 및 건축 특성 조회
- 시설 규모 및 주요 운영정보 조회
- 산림 인접 여부 등 외부 위험특성 확인
- 최근접 소방기관과의 접근성 분석
- 시설 유형별 대피체계 및 표준모델 개발을 위한 기초자료 제공

## GitHub Pages

본 시스템은 별도의 웹 서버 없이 GitHub Pages 기반의 정적 웹 서비스 구현

1. 시설 현황자료 구축
2. 시설 주소 및 좌표 검증
3. 입지, 산림인접, 건축, 규모, 유형화
4. 소방서, 119안전센터 위치 검증
5. 119지역대 위치 검토
6. 시설과 소방기관간 직선 거리 산정
7. 최근접 소방기관 지정
8. 도로거리 및 예상 이동시간 산정
9. 소방대응여건 분류 및 카카오 이동경로 분류
10. GitHub Pages 배포
